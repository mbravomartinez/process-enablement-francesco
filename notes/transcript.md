# Process Exploration — reMarkable brainstorm (2026-08-24)

## Page 1 — what the output must contain
- Personas involved + departments
- Type of systems involved
- Process Flow -> example of the flow
- Explanation of all the process-specific terms (you can choose language)
- Most frequent deviations explained + most probable root causes + what financial impact do these have
- Biggest use cases a kind of Digital Transformation would look at

Inputs: Process / Industry / Selected language

## Page 2 — UI
Language: when selected, everything changes in that language.
- Process: Is it core for business, what is INPUT / OUTPUT + why is it relevant for organisation
- Personas: people involved in the process
- Systems: which systems are usually kept and to make which [?]

TABS: Process Step-by-Step (each step has description + example) | Process Variants (w/ Financial Impacts) w/ Root causes | Terminology to handle discovery workshops | Use Cases

Layout: left = flow diagram, steps clickable -> pop up with description & example. Right = CHAT TO ASK INFOS.
